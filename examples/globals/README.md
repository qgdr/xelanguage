# Xe 全局可变变量

模块顶层的 `let[mut] COUNT: i32 = 0;` 建立程序期间共享的可写存储。
函数调用不会重新初始化它；全局地址可以从函数返回。
`pub let[mut]` 可以通过 `use` 导入，模块路径、别名和重导出访问同一个对象。

在仓库根运行：

```sh
./xe run examples/globals/main.xe
```

输出：

```text
tick=1
tick=2
through-pointer=10
local=100 global=10
```

当前全局可变变量要求显式类型、初值和 Copy 类型。初值支持字面量、正负号、
元组、内联数组、Copy 结构体、模块只读常量，以及全局存储的地址；
函数调用与其他运行时初始化尚未支持。String、Vec、File 等资源须由函数内的拥有者管理。

`COUNT@` 只允许读取，`COUNT@[mut]` 允许写入；局部同名变量拥有独立存储。
把局部对象的地址保存到全局可能产生悬垂指针，编译器会报告能检测到的风险。
全局变量本身不提供线程同步，多线程写入仍需锁或其他同步方案。
