# 依赖任务规划器

这个Xe程序处理8个任务：计算稳定的拓扑顺序、每个任务的最早完成时间和总工期，
遇到循环依赖则报告已经完成的任务数。算法完整写在[main.xe](main.xe)中。

## 运行

在仓库或源码包根目录执行：

```sh
./xe run examples/dependency-planner/main.xe --cc gcc
```

默认依赖关系为：

```text
0 → 1 → 2 → 3 → 4 → 6 → 7
              ↘ 5 ↗
```

任务时长为`[2,3,4,2,5,2,3,1]`，输出：

```text
case 0
row 0 0
complete 20
task 0 0 2
task 1 1 5
task 2 2 9
task 3 3 11
task 4 4 16
task 5 5 13
task 6 6 19
task 7 7 20
```

`Task`结构体把同一任务的状态放在一起；`ready`和`complete`方法明确接收方式。
图与任务表采用固定数组，原坐标View用于保持任务编号，枚举表达成功或检测到循环。
输出中的任务完成时间按原任务编号排列，调度槽顺序是另一组信息。

容量8是这个项目的选择，不是语言的数组长度上限。输入写在main里，
本版示例不提供运行时文件读取、模块或命令行参数解析接口。
