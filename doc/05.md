# 控制流

## 条件表达式

`if` 是表达式。作为值使用时，每条可继续执行的分支必须产生兼容类型：

```xe
let label: str = if score >= 60 {
    "passed"
} else {
    "failed"
};
```

没有 `else` 的 `if` 返回 `Unit`。条件必须是 `bool`，整数不会被隐式解释为真假。

## while 循环

```xe
let[mut] index: usize = 0;
while index < bytes.len() {
    consume(bytes[index]);
    index = index + 1;
}
```

`break;` 结束最近一层循环，`continue;` 开始下一轮。首版循环本身返回 `Unit`。

## for 循环

范围、数组、切片使用内建规则；自定义对象提供
`fn next(self: Self@[mut]) -> Step[T]` 方法；`Step::Item[value]` 产生 T，`Step::Stop` 结束。
当前不要求/未实现公共 IntoIterator Trait 或关联 Item 类型，详见 [第 26 章](26.md)。

```xe
for number in 1..4 {
    println("{}", number);
}

let values = [10, 20, 30];
for value: i32@ in values {
    println("value = {}", value);
    println("address = {:p}", value);
}
```

迭代项表示什么，由来源协议明确决定。遍历现存容器元素时绑定元素指针；
生成新值时绑定生成的值，不把值暗中取地址，也不把指针暗中解引用：

- 整数范围产生整数值；
- 数组、Vec[T] 与 Slice[T] 默认产生 T@，不移动元素；
- SliceMut[T] 产生 T@[mut]；
- 自定义 `next(): Step[T]` 和 `from_fn` 的循环变量就是 `Item` 负载 `T`：`T` 是值就获得值，
  `T` 本身是指针就获得指针；`Step::Stop` 使循环结束，`Step::Item[Maybe::None]` 不会结束。

```xe
let[mut] values = [1, 2, 3];
for value: i32@[mut] in values.slice_mut(0..3) {
    value# = value# * 2;
}
```

普通指针允许别名，不禁止其他名称访问容器；移动/释放拥有存储可能让已取得的元素指针
失效，能够识别时给 warning，不承诺内存安全。数组/切片迭代已有实际后端运行。
Vec 已支持上述元素指针遍历，见第 27 章；iter_mut()/into_iter() 通用容器接口和完整
迭代 Trait 尚未实现，不能把目标 API 当成可执行接口。

对自定义迭代器写 for item in iterator，源在进入循环前复制或移动一次，隐藏的循环
存储拥有它；资源迭代器即使零次迭代也已经移动，结束或跳出循环时清理。
写 for item in iterator@[mut] 则只复制指针，保留外部环境和进度，不清理外部拥有者。
每轮拥有元素在本轮结束时清理，移出的资源由接收者清理；continue/break/return 均覆盖。
这与数组/切片默认产出元素指针的既有规则分开说明，不隐藏容器所有权转换。

## 范围

- `start..end`：包含起点，不包含终点；
- `start..=end`：包含两端；
- `start..`、`..end`、`..`：开放范围，主要作为切片方法的参数。
