# 控制流

## 条件表达式

`if` 是表达式。作为值使用时，每条可继续执行的分支必须产生兼容类型：

```xe
let label: str = if score >= 60 {
    "passed"
} else {
    "failed"
};
```

没有 `else` 的 `if` 返回 `Unit`。条件必须是 `bool`，整数不会被隐式解释为真假。

## while 循环

```xe
let[mut] index: usize = 0;
while index < bytes.len() {
    consume(bytes[index]);
    index = index + 1;
}
```

`break;` 结束最近一层循环，`continue;` 开始下一轮。首版循环本身返回 `Unit`。

## for 循环

`for item in source` 使用 `source` 的 `IntoIterator` 实现：

```xe
for number in 1..4 {
    println("{}", number);
}

let values = [10, 20, 30];
for value: i32@ in values {
    println("value = {}", value);
    println("address = {:p}", value);
}
```

迭代项是值还是借用，由迭代器的 `Item` 类型决定：

- 整数范围产生整数值；
- 数组和 `Vec[T]` 的默认迭代产生 `T@`；
- `.iter_mut()` 产生 `T@[mut]`；
- `.into_iter()` 消耗容器并产生拥有所有权的 `T`。

```xe
let[mut] values = [1, 2, 3];
for value: i32@[mut] in values.iter_mut() {
    value# = value# * 2;
}
```

循环期间，迭代器持有相应借用。因此不能在默认迭代时移动容器，也不能在 `.iter_mut()`
期间通过其他名称访问容器。

这些借用期限制属于检查规则，不提供关闭入口。默认迭代得到 T@，
.iter_mut() 得到 T@[mut]；当前数组/切片迭代运行支持尚未接入后端。

## 范围

- `start..end`：包含起点，不包含终点；
- `start..=end`：包含两端；
- `start..`、`..end`、`..`：开放范围，主要作为切片方法的参数。
