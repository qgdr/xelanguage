# 结构体、数组、字符串与切片

## 结构体

```xe
struct[region r] Person {
    age: i32,
    name: str[r],
}
```

区域附件是历史/预留能力，不是普通指针的强制安全条件；一般结构体可以直接保存 str。
编译器追踪可识别的来源风险，无法证明有效或发现逃逸时给 warning，不强制 Rust 式区域证明。

结构体字面量使用 `.field` 明确表示内部字段。`=` 复制字段，`<<` 转移不可复制字段值：

```xe
let name: str = "Tom";
let person << Person {
    .age = 20;
    .name = name;
};

struct Message {
    text: String,
}

let text: String << String::from("hello");
let message: Message << Message {
    .text << text;
};
```

每个字段必须且只能初始化一次；字段顺序不影响含义。首版不提供隐藏的字段默认值。
用户结构体没有显式 Copy 就不能用 = 初始化整个对象。未知泛型 T 的字段可以使用
value >> .field;，按类型复制或移动，而不扩大 = 或 << 的含义。

## 元组

```xe
let point: tuple[i64, i64] = tuple[10, 20]; // 字面量逐元素按预期类型推导。
let x = point.0;
let tuple[left: i64, right: i64] = point; // 解包后创建两个新变量。
```

单元素元组写作 `tuple[value]`，类型为 `tuple[T]`，不要求尾随逗号。
`tuple[a, b]` 使用位置索引 `.0`、`.1` 访问成员，也可以通过 `let tuple[a, b]` 解包。
空元组 `tuple[]` 暂不增加；空 `{}` 仍是空块。
无内容的值统一使用 `unit: Unit`。() 只作调用与分组，包括类型分组。
`tuple` 前缀让元组与代码块明确区分，不借助逗号猜测花括号的含义。
资源元组使用 `<<` 解包，`>> tuple[a, b]` 是通用转送；完整规则见第 23 章。

## 数组

`Array[T, N]` 是长度在编译期确定的连续数组：

```xe
let months: Array[str, 3] = ["January", "February", "March"];
let first: str = months[0];
```

数组默认迭代器产生 `T@`；当前通过 `.slice_mut(range)` 的 SliceMut[T] 产生 `T@[mut]`。
`.iter_mut()` / `.into_iter()` 是未来容器接口，尚未实现，不引入独占借用要求。

## str：只读 UTF-8 视图

`str` 是一个不可变、可复制的视图，概念上包含：

```text
数据地址 + 字节长度（编译器另外跟踪能够识别的地址风险）
```

字符串字面量具有静态生命周期：

```xe
let greeting: str = "hello";
```

允许 str@：它借用视图描述符，不是字符串字节的地址。
需要底层字节地址时显式调用：

```xe
let data: u8@ = greeting.data();
let descriptor: str@ = greeting@;
let length: usize = greeting.len();
```

标准构造接口检查合法 UTF-8；悬垂/外部危险地址不能靠 str 类型自动修复。
它不允许用整数直接索引，因为“第几个”可能表示字节、
Unicode 标量或用户看到的字形：

```xe
text[0]; // 编译错误
```

应当明确选择观察方式：

```xe
for byte in text.bytes() {
    // byte: u8
}

for character in text.chars() {
    // character: char
}

let prefix: str? = text.slice_bytes(0..5); // 当前接口：失败为 None。
```

## String：拥有缓冲区

`String` 是标准库提供的、可增长、拥有 UTF-8 缓冲区的移动类型：

```xe
let[mut] text: String << String::from("hello");
text.push_str(", world");

let view: str = text.as_str();
```

`as_str()` 创建非拥有只读视图。改变缓冲区、移动或析构 String 后，旧视图可能失效；
编译器能够识别时给 warning 并传播 unsafe，仍允许编译，而不是禁止普通指针别名。
切片基础运行库已实现；bytes/chars 仍是待实现的标准库接口。

## Slice 与 SliceMut

`Slice[T]` 是只读、非拥有的连续元素视图；`SliceMut[T]` 是可写视图，允许地址别名：

`Array[T, N]`、`Slice[T]` 和 `SliceMut[T]` 均支持 `.len() -> usize`。
`let[mut] view: Slice[T]` 只允许替换 view 描述符，不能写入 `view[index]`，
也不能通过描述符的可写指针取得元素写权限；要修改元素须使用 SliceMut。

```xe
let values = [1, 2, 3, 4, 5];
let middle: Slice[i32] = values.slice(1..4);

let[mut] target = [1, 2, 3, 4, 5];
let[mut] tail: SliceMut[i32] = target.slice_mut(3..);
tail.fill(0);
```

两者都包含数据地址和长度；复制不会复制元素或延长底层对象生命，可能失效时给 warning。
命名区域 Slice[T, r]、SliceMut[T, r] 属于历史/预留能力，普通使用不要求区域证明。

当前 Array/Slice 切片方法越界时终止，不返回 Maybe；str.slice_bytes 返回 str? 并检查 UTF-8
边界。统一的可恢复切片错误 API 仍待讨论，不把当前终止策略说成已冻结的语言契约。
[unsafe] 是可传播的地址风险注记，不增加写权限或资源所有权，不能修复悬垂指针。
