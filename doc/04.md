# 结构体、数组、字符串与切片

## 结构体

```xe
struct Person[region r] {
    age: i32,
    name: str[r],
}
```

保存 `str` 或切片等借用视图的结构体必须声明区域。只含拥有值和普通标量的结构体不需要。

结构体字面量使用 `.field` 明确表示内部字段。`=` 复制字段，`<<` 传递字段值：

```xe
let name: str = "Tom";
let person = Person {
    .age = 20;
    .name = name;
};

struct Message {
    text: String,
}

let text: String << String::from("hello");
let message: Message << Message {
    .text << text;
};
```

每个字段必须且只能初始化一次；字段顺序不影响含义。首版不提供隐藏的字段默认值。

## 元组

```xe
let point: (i32, i32) = (10, 20);
let x = point.0;
```

单元素元组写作 `(value,)`。无内容的值统一使用 `unit: Unit`。

## 数组

`Array[T, N]` 是长度在编译期确定的连续数组：

```xe
let months: Array[str, 3] = ["January", "February", "March"];
let first: str = months[0];
```

数组默认迭代器产生 `T@`；`.iter_mut()` 产生 `T@[mut]`。

## str：只读 UTF-8 视图

`str` 是一个不可变、可复制的视图，概念上包含：

```text
数据地址 + 字节长度 + 由编译器跟踪的借用区域
```

字符串字面量具有静态生命周期：

```xe
let greeting: str = "hello";
```

禁止 `str@`。`str` 已经包含数据地址和长度，再取得它的普通安全指针只会增加不必要的间接
层。需要底层字节地址时显式调用：

```xe
let data: u8@ = greeting.data();
let length: usize = greeting.len();
```

`str` 始终保证内容是合法 UTF-8。它不允许用整数直接索引，因为“第几个”可能表示字节、
Unicode 标量或用户看到的字形：

```xe
text[0]; // 编译错误
```

应当明确选择观察方式：

```xe
for byte in text.bytes() {
    // byte: u8
}

for character in text.chars() {
    // character: char
}

let prefix: str?[Utf8BoundaryError] = text.slice_bytes(0..5);
```

## String：拥有缓冲区

`String` 是标准库提供的、可增长、拥有 UTF-8 缓冲区的移动类型：

```xe
var text: String << String::from("hello");
text.push_str(", world");

let view: str = text.as_str();
```

`as_str()` 创建受 `text` 生命周期约束的只读视图。该视图存在期间，不能执行可能重新分配
字符串缓冲区的修改，也不能移动或析构 `text`。

## Slice 与 SliceMut

`Slice[T]` 是只读、非拥有的连续元素视图；`SliceMut[T]` 是独占可写视图：

```xe
let values = [1, 2, 3, 4, 5];
let middle: Slice[i32] = values.slice(1..4);

var target = [1, 2, 3, 4, 5];
var tail: SliceMut[i32] << target.slice_mut(3..);
tail.fill(0);
```

两者都包含数据地址和长度，并受底层对象生命周期约束。公开 API 在确有多个来源时可以写
命名区域：`Slice[T, r]`、`SliceMut[T, r]`。

切片范围越界是可检查错误。编译期能够确定越界时直接报错；运行时范围使用返回结果的安全
方法。只有 `unsafe` API 才能跳过检查。
