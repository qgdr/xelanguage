# 管道表达式

`|>` 把左侧结果送入右侧调用，使连续变换从左向右阅读：

```xe
let result << input
    |> trim
    |> parse_i32;
```

等价于：

```xe
let result << parse_i32(trim(input));
```

右侧还有其他参数时，使用且只能使用一个 `_` 标出管道值的位置：

```xe
let result = value
    |> multiply(_, 2)
    |> add(10, _);
```

管道不是新的调用机制，不改变复制、移动、借用或错误传播规则。左侧值进入函数参数时，和
普通函数调用完全相同。

首版不因为管道引入专用 Lambda 语法。需要复杂控制流时，命名一个普通函数通常更容易被
人类和工具理解。
