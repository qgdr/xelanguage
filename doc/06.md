# 枚举、模式选择与分支管道

## 枚举

```xe
enum Token {
    End,
    Identifier[String],
    Integer[i64],
}
let token: Token << Token::Identifier[String::from("name")];
```

声明和构造的负载使用 []，调用使用 ()。无负载变体直接写 Token::End。
任意变体含非 Copy 负载时，整个枚举不能 Copy。

## 分支选择与负载处理分开

```xe
fn describe(token: Token@) -> str {
    token ?[@] {
        Token::Identifier :> text: String@ -> "identifier",
        Token::Integer :> number: i64@ -> "integer",
        Token::End :> _ -> "end",
    }
}
```

:> 左侧只选择模式，右侧只接处理函数或管道参数绑定。它是一个完整的分支管道符号，
不是类型冒号。参数的 name: Type 仍仅声明名称及类型；-> 后是立即执行的处理正文。
不能写 Token::End :> 0、旧的模式 > expression 或模式 => expression。

支持命名处理函数，也支持 fn 开头的匿名函数；所选处理函数只执行一次，未选分支不求值
其处理函数表达式：

```xe
token ?[@] {
    Token::Identifier :> identifier_length,
    Token::Integer :> number: i64@ -> number#,
    Token::End :> _ -> 0,
}
```

无负载变体调用零参数函数。_ -> expression 是忽略负载或无负载事件的统一适配器，
不制造假的 Unit 参数。分支用逗号分隔，整个匹配用花括号确定边界。

## 按值与借用匹配

- token ? { ... } 按值匹配：资源对象消耗，负载按普通参数规则复制或移动。
- token ?[@] { ... } 共享借用匹配：普通负载 T 统一作为 T@ 传给处理函数，标量也一样。
- token ?[@[mut]] { ... } 可写匹配：普通负载作为 T@[mut] 传入，需要检查模式及可写来源。
- 对 Token@ 或 Token@[mut] 匹配必须显式选择借用模式；不隐式取走所指对象。
- 类型注解只校验输入类型，不选择复制或借用；共享匹配的 number: i64 因类型不符报错。
  需要整数值时明确读 number#。不接受绑定名后附加 @ 的特殊模式声明。
- str、Slice[T] 等 Copy 借用视图例外地复制视图，不生成 str@，底层区域仍受原对象约束。
  SliceMut[T] 不是 Copy 视图：共享匹配给出 SliceMut[T]@，不能移走它。
  首版可写匹配不支持绑定这些视图负载；可以忽略负载或改用共享匹配和专门 API。
- 负载自身是 U@ 时，共享匹配得到 U@@，不自动展平。可写指针负载的共享借用不能
  取得内部可写能力；需先结束共享借用，再建立合法的独占重借用。
- 被匹配指针只解引用到当前枚举或标量存储，不自动穿透任意层指针。
- 默认模式支持 ?[@]，但指针不承诺只读、生命周期或别名安全；所有权限制仍保留。

```xe
fn into_text(token: Token) -> String {
    token ? {
        Token::Identifier :> text: String -> text,
        _ :> _ -> String::from(""),
    }
}
```

资源负载不能通过 text# 转送所有权。负载借用仍有效时，检查模式禁止移动、析构或更换
整个枚举的变体；返回内部指针须受原对象区域约束。匹配对象只求值一次。

按值匹配先选分支，再转交其输入；没有交给处理函数的资源在分支退出时清理。类型自己
实现自定义 Drop 时，首版禁止抽取其资源负载，因为 Drop 可能读取该负载。仅仅包含 String
不等于枚举自己实现了 Drop；这种普通枚举仍支持资源负载转移。

## 模式和多负载

模式只选择，不定义变量；变量由 :> 后的处理参数声明。首版支持字面量、_、元组、
具名枚举变体及 [] 中的字面量/忽略/嵌套选择。裸变量不能表示相等比较或兜底绑定。
变体后不写 [] 表示选择该变体的任何负载，写 [] 则按位置进一步筛选：

```xe
token ?[@] {
    Token::Integer[0] :> _ -> "zero",
    Token::Integer :> _ -> "nonzero integer",
    Token::Identifier :> _ -> "identifier",
    Token::End :> _ -> "end",
}
```

模式筛选读取逻辑值，不因此复制或移动资源。嵌套筛选不直接绑定深层字段；处理函数仍
收到最外层所选变体的完整负载。需要深层数据时，再进行一次明确的匹配。

一个负载用 name: Type -> expression；多个负载用参数附件 [x: T, y: U] -> expression，
按变体声明顺序传入命名函数的多个普通参数：

```xe
enum PointEvent { Pair[i32, i32], }
fn sum(event: PointEvent) -> i32 {
    event ? {
        PointEvent::Pair :> [x: i32, y: i32] -> x + y,
    }
}
```

裸 _ 模式选择其他任何值：处理函数接收整个匹配对象，而非猜测各变体的不同负载。
标量/元组模式也传入完整对象；_ -> 可以统一忽略。零负载绑定只允许 _ -> 或零参数函数。
穷尽性必须检查，按源码顺序选首个匹配分支，完全不可达的分支报错。
所有继续执行的分支调用结果须类型兼容；Never 分支可与任何正常结果组合。

## 唯一正式入口

正式形式只有 subject ? { selector :> handler, ... } 及借用修饰。旧 match、> 分支、
=> 分支和在选择器中绑定名称的写法不保留兼容语义，应给出迁移提示。
数字 1> / 2> 只用于 Maybe；一般整数匹配使用 1 :> handler，不与比较冲突。
