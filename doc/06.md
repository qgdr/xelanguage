# 枚举与模式匹配

编译器使用枚举表示词法单元、语法树节点、类型和诊断类别。

## 枚举

```xe
enum Token {
    End,
    Identifier[String],
    Integer[i64],
    Punctuation[char],
}
```

变体位于类型命名空间中：

```xe
let end: Token << Token::End;
let number: Token << Token::Integer[42];
```

变体的 `[]` 声明或附带负载；函数和方法调用使用 `()`。构造变体时，负载按普通值传递规则
复制或移动。没有负载的变体直接写名称，不加空括号。分组和元组仍使用 `()`。

只要任意变体含有移动字段，整个枚举就是移动类型。

## match 表达式

```xe
fn token_name(token: Token@) -> str {
    match token {
        Token::End -> "end",
        Token::Identifier[_] -> "identifier",
        Token::Integer[_] -> "integer",
        Token::Punctuation[_] -> "punctuation",
    }
}
```

分支写作 `pattern -> expression`，使用 `,` 分隔。逗号只是同级选项分隔符，不会像语句
分号一样丢弃分支值。

模式可以绑定变体数据：

```xe
let length = match token {
    Token::Identifier[text] -> text.len(),
    _ -> 0,
};
```

按值匹配会消耗移动类型；匹配 `T@` 只借用内部数据。`_` 忽略一个值。

## 穷尽性

`match` 必须覆盖所有可能情况。遗漏分支时，诊断应直接列出缺少的变体。作为表达式使用时，
所有能够继续执行的分支必须产生兼容类型。

首版模式支持：

- 字面量；
- `_`；
- 名称绑定；
- 元组；
- 枚举变体及位置参数；
- 使用 `|` 组合不产生冲突绑定的模式。

结构体解构、范围模式和匹配守卫可以在首次自举后增加。
