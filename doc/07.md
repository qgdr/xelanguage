# 方法与关联函数

方法写在 `impl Type` 中。没有 `self` 参数的是关联函数，通过 `Type::function()` 调用：

```xe
struct Circle {
    x: f64,
    y: f64,
    radius: f64,
}

impl Circle {
    fn new(x: f64, y: f64, radius: f64) -> Circle {
        Circle {
            .x = x;
            .y = y;
            .radius = radius;
        }
    }

    fn area(self: Self@) -> f64 {
        PI * self.radius * self.radius
    }

    fn resize(self: Self@[mut], radius: f64) {
        self.radius = radius;
    }

    fn into_radius(self: Self) -> f64 {
        self.radius
    }
}
```

三种接收者含义：

类型、写权限和所有权始终检查。Self 按值取得所有权；
Copy 类型复制，资源类型移动，不根据调用写法偷偷改变接收者规则。

- `self: Self@`：只读普通指针；
- `self: Self@[mut]`：可写普通指针，允许别名；
- `self: Self`：按值取得对象，移动类型会被消耗。

调用示例：

```xe
let[mut] circle << Circle::new(0.0, 0.0, 10.0);
let area = circle.area();
circle.resize(20.0);
```

值接收者调用 `self: Self@` 或 `Self@[mut]` 方法时可以自动取地址；
已有 `Self@` / `Self@[mut]` 指针调用权限相容的指针接收者方法时直接传递指针。
若方法声明 `self: Self` 且真正消耗非 Copy 对象，`pointer.method()` 必须报错：
指针没有所指资源的所有权，显式 `(pointer#).method()` 也不能移走它。
若 `Self` 实现 Copy，按值调用取得副本而不消耗原对象；这一边界与资源移动分开。
返回的内部指针/视图不延长 self 的生命周期；能够识别失效风险时给 warning。
普通函数参数仍须显式传 `value@`。

字段和方法都使用 `.`：`object.name` 始终是字段，`object.name()` 始终是方法。
如果字段本身保存函数值，调用写 `(object.name)(argument)`：括号明确先取得字段再调用，
不按同名方法是否存在来改变解析。这一写法已经由当前前端及 C 后端支持。
