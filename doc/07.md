# 方法与关联函数

方法写在 `impl Type` 中。没有 `self` 参数的是关联函数，通过 `Type::function()` 调用：

```xe
struct Circle {
    x: f64,
    y: f64,
    radius: f64,
}

impl Circle {
    fn new(x: f64, y: f64, radius: f64) -> Circle {
        Circle {
            .x = x;
            .y = y;
            .radius = radius;
        }
    }

    fn area(self: Self@) -> f64 {
        PI * self.radius * self.radius
    }

    fn resize(self: Self@[mut], radius: f64) {
        self.radius = radius;
    }

    fn into_radius(self: Self) -> f64 {
        self.radius
    }
}
```

三种接收者含义：

下列只读和独占保证适用于 --check-borrows；默认模式统一用 Self@ 表示非拥有指针，
不写修饰，也不检查别名与生命周期。Self 按值取得所有权的规则两种模式相同。

- `self: Self@`：共享只读借用；
- `self: Self@[mut]`：独占可写借用；
- `self: Self`：按值取得对象，移动类型会被消耗。

调用示例：

```xe
var circle = Circle::new(0.0, 0.0, 10.0);
let area = circle.area();
circle.resize(20.0);
```

方法调用可以根据接收者类型自动建立持续到调用结束的短借用。若方法返回与 `self` 关联的
借用，生命周期默认来自 `self`。

字段和方法都使用 `.`：`object.name` 始终是字段，`object.name()` 始终是方法。
