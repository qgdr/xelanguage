# Trait、Copy 与析构

Trait 描述类型能够提供的静态行为：

```xe
trait Display {
    fn display(self: Self@, output: Formatter@[mut]);
}

impl Display for Position {
    fn display(self: Self@, output: Formatter@[mut]) {
        output.write("{}:{}", self.line, self.column);
    }
}
```

没有函数体的方法必须由实现类型提供；有函数体的方法是默认实现。第一次自举只需要静态
分派，不要求 Trait 对象和运行时虚表。

## Copy

`Copy` 是编译器识别的标记 Trait：

```xe
impl Copy for Position;
```

只有所有字段都实现 `Copy` 且类型没有实现 `Drop` 时，编译器才接受这个实现。整数、布尔、
字符、安全借用、`str` 和只读切片等标准类型由标准库或编译器提供 `Copy`。

泛型可以要求复制能力：

```xe
fn duplicate[T](value: T) -> (T, T)
where T implements Copy
{
    (value, value)
}
```

`Clone` 与 `Copy` 不同：`Clone` 是可能分配资源的显式普通方法，移动类型可以实现它。

## Drop

`Drop` 在值离开作用域时释放资源：

```xe
struct File {
    handle: usize,
}

impl Drop for File {
    fn drop(self: Self@[mut]) {
        os::close(self.handle);
    }
}
```

析构顺序：

1. 同一作用域中的局部变量按完成初始化的逆序析构；
2. 结构体先执行自己的 `drop`；
3. 再按字段声明顺序析构仍有效的字段；
4. 已经移动出去的值或字段不会再次析构。

编译器自动生成字段析构代码。用户的 `drop` 不应手动重复析构字段。`Copy` 与 `Drop` 互斥。
