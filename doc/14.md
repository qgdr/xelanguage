# 词法与语法摘要

本章给出实现解析器所需的规范摘要。章节示例比这里的 EBNF 更容易阅读；两者冲突时应当先
修正文档，使二者保持一致。

冻结标识：xe-bootstrap-0.1；具体冻结与保留边界见第 17 章。

## 词法

```text
identifier  = (letter | "_") (letter | digit | "_")* ;
integer     = decimal | "0x" hex+ | "0o" octal+ | "0b" binary+ ;
float       = decimal "." decimal exponent? | decimal exponent ;
exponent    = ("e" | "E") ("+" | "-")? decimal ;
string      = '"' (escaped-character | non-quote-character)* '"' ;
character   = "'" (escaped-character | unicode-scalar) "'" ;
byte          = "b" character ;
line-comment  = "//" ... newline ;
block-comment = "/*" ... "*/" ;
doc-comment   = "///" ... newline | "//!" ... newline ;
```

块注释允许嵌套。源码必须是 UTF-8。换行不是语句结束符。

字节字面量复用字符字面量外形，但内容必须是 ASCII 字节或取值不超过 255 的转义。

前端支持转义 \\, \", \', \n, \r, \t, \0、控制转义及 1–3 位八进制；
\xHH、\uHHHH、\UHHHHHHHH 分别表示字节码点及 Unicode 码点。未知转义和代理码点报错。

核心关键字：

```text
let var const fn return if else while for in break continue
struct enum trait impl for where implements
pub use as crate self super region extern unsafe
true false unit None
```

## 名称、路径与字面量

```text
path-root = "crate" | "self" | "super" | identifier ;
path      = path-root ("::" identifier)* ;
none-variant-path = "Maybe" "::" "None" ;
literal   = integer | float | string | character | byte
          | "true" | "false" | "unit" ;
```

`crate`、`self`、`super` 只能出现在路径首段。普通名称和类型名称都使用同一条 `path` 规则。

## 模块项目

```text
module      = item* ;
item        = use-item
            | const-item
            | function-item
            | struct-item
            | enum-item
            | trait-item
            | impl-item
            | extern-item ;
visibility  = "pub"? ;
use-item    = "use" path ("as" identifier)? ";"
            | "use" path "::" "{" use-name ("," use-name)* ","? "}" ";" ;
use-name    = identifier ("as" identifier)? ;
extern-item = "extern" string "{" extern-function* "}" ;
extern-function = "fn" identifier "(" parameters? ")" ("->" type)? ";" ;
```

普通语句不能直接出现在模块顶层。

## 声明与函数

```text
binding     = ("let" | "var") identifier (":" type)?
              (("=" | "<<") expression)? ";" ;
const-item  = visibility "const" identifier ":" type "=" expression ";" ;
function-item = visibility "fn" identifier generic-params?
                "(" parameters? ")" ("->" type)? where-clause? block ;
parameters  = parameter ("," parameter)* ","? ;
parameter   = "var"? identifier ":" type ;
generic-params = "[" generic-param ("," generic-param)* ","? "]" ;
generic-param  = identifier | "region" identifier ;
where-clause   = "where" constraint ("," constraint)* ","? ;
constraint     = type "implements" type ;
```

## 类型

```text
type          = primary-type type-postfix* ;
primary-type  = path type-arguments? | "None" | function-type
              | "(" type "," (type ("," type)* ","?)? ")" ;
type-arguments = "[" generic-argument ("," generic-argument)* ","? "]" ;
generic-argument = type | integer ;
function-type = "fn" "(" (type ("," type)* ","?)? ")" "->" type ;
type-postfix  = "@" borrow-modifier?
              | "?" ("[" type "]")? ;
borrow-modifier = "[" ("mut" ("," identifier)? | identifier) "]" ;
```

示例：`i32@`、`i32@[mut]`、`T@[r]`、`T@[mut, r]`、`T?[E]`、`Slice[T, r]`。

泛型实参中的裸名称先按普通类型路径解析，再根据声明的参数种类判定它代表类型还是区域；
因此语法分析器不需要为 `r` 增加上下文相关词法规则。

implements 右侧使用完整的 Trait 类型应用，名称解析后必须确认为 Trait，
例如 F implements CallOnce[(i32,), i32]，不是任意普通数据类型。

## 复合类型

枚举声明、构造和模式中的负载都使用 `[]`；无负载变体直接写名称，不加 `[]`。

```text
struct-item = visibility "struct" identifier generic-params?
              (";" | "{" field-decl* "}") ;
field-decl  = visibility identifier ":" type "," ;
enum-item   = visibility "enum" identifier generic-params?
              "{" variant-decl* "}" ;
variant-decl = identifier ("[" type-list "]")? "," ;
trait-item  = visibility "trait" identifier generic-params?
              "{" trait-member* "}" ;
impl-item   = "impl" generic-params?
              (type | path "for" type) where-clause?
              (";" | "{" impl-member* "}") ;
type-list    = type ("," type)* ","? ;
trait-member = visibility "fn" identifier generic-params?
               "(" parameters? ")" ("->" type)? where-clause?
               (";" | block) ;
impl-member  = function-item ;
```

## 语句、函数值与管道

```text
block         = "{" statement* expression? "}" ;
statement     = binding | "return" expression? ";"
              | "break" ";" | "continue" ";" | assignment ";"
              | block-control | expression ";" ;
block-control = if-expression | while-expression | for-expression ;
assignment    = place ("=" | "<<") expression | expression ">>" place ;
if-expression = "if" condition block ("else" (if-expression | block))? ;
while-expression = "while" condition block ;
for-expression = "for" identifier (":" type)? "in" condition block ;
unsafe-expression = "unsafe" block ;
struct-literal = path "{" field-init* "}" ;
field-init     = "." identifier ("=" | "<<") expression ";" ;

anonymous-function = "fn" captures? "(" parameters? ")" ("->" type)? block ;
captures       = "[" capture ("," capture)* ","? "]" ;
capture        = identifier ("@" borrow-modifier?)? ;
handler        = handler-binding "->" expression
               | path | anonymous-function | "(" expression ")" ;
handler-binding = handler-parameter
                | "[" handler-parameter ("," handler-parameter)* ","? "]" ;
handler-parameter = (identifier | "_") (":" type)? ;
```

具名函数与匿名函数的参数都必须有类型，匿名函数有预期签名时才可推导参数类型。
类型注解是校验，不改变负载访问方式。多负载处理绑定用 []，函数参数列表仍用 ()。
首版 for 只支持单项绑定，复杂解构通过循环正文匹配完成。

分号仍结束普通语句；if / while / for 作为块控制语句可以省略尾随分号，这一惯例与示例
保持一致。只有块尾、无分号的最终表达式产生块结果；处于非尾部的块控制语句丢弃结果。
资源结果若被丢弃仍需自动 drop。if 的条件与循环来源使用受限表达式入口，禁止无括号的
结构体字面量抢占随后正文的 {；需要结构体值作为条件子表达式时加括号。

```text
expression     = branch-expression ;
branch-expression = pipe-expression branch-suffix? ;
branch-suffix  = "?" match-borrow? (result-arm result-arm | "{" named-arm+ "}") ;
match-borrow   = "[@]" | "[@[mut]]" ;
result-arm     = ("1" | "2") ">" handler ;
named-arm      = selector ":>" handler "," ;
pipe-expression = range-expression ("|>" handler)* ;
range-expression = logical-or ((".." | "..=") logical-or?)?
                 | (".." | "..=") logical-or? ;
logical-or     = logical-and ("or" logical-and)* ;
logical-and    = comparison ("and" comparison)* ;
comparison     = additive (("<" | "<=" | ">" | ">=" | "==" | "!=") additive)* ;
additive       = multiplicative (("+" | "-") multiplicative)* ;
multiplicative = cast (("*" | "/" | "%") cast)* ;
cast           = unary ("as" ("[" ("checked" | "wrap") "]")? type)* ;
unary          = ("not" | "+" | "-") unary | postfix ;
postfix        = primary postfix-operation* ;
postfix-operation = arguments | bracket-arguments | "." identifier
                  | "@" borrow-modifier? | "#" | "?" "[" "return" "]" ;
arguments      = "(" (expression ("," expression)* ","?)? ")" ;
bracket-arguments = "[" expression ("," expression)* ","? "]" ;
tuple          = "(" expression "," (expression ("," expression)* ","?)? ")" ;
array          = "[" (expression ("," expression)* ","?)? "]" ;
place          = path (("." identifier) | ("[" expression "]") | "#")* ;
primary        = literal | path | none-variant-path | "None"
               | tuple | array | struct-literal | block | anonymous-function
               | if-expression | unsafe-expression | "(" expression ")" ;
```

上面的语法为结构摘要，condition 使用与 expression 相同的优先级，但限制最外层结构体
字面量。handler 的绑定分支先前瞻参数及 ->；否则按函数路径、fn 或括号目标解析。
参数绑定的 expression 贪婪包含后续管道，但不能越过当前分支的外层分隔符。
不同嵌套分支的范围由括号/花括号维护，不能用逐行扫描或扫描 1> 字符串决定正文结束。

每个数字匹配必须恰好有一个 1>、一个 2>。1> foo 是调用，1> _ -> foo 返回函数值。
禁止不可调用变量、字面量、直接调用 foo(_) / foo(1)、旧的 _ 占位符及省略参数的 ->。
函数类型变量可作为目标；(make_handler()) 显式求值并调用返回的处理函数。
无负载分支只接受零参数函数或 _ -> 正文；_ 不是可读取的变量。
未选分支目标及正文不执行。fn 内 return 只退出该函数；处理参数绑定的 return
作用于外层所在函数。所有继续执行分支的调用结果必须兼容。

普通 ? 位于管道之后，?[return] 位于后置层。匹配的接收值只求值一次；
绑定优先级表见第 02 章。赋值和值传递仅是语句，a = b = c 不合法。
类型修饰按从左到右组成；在 as 后返回结果类型与表达式分流无法凭意图区分时使用括号：
(value as T) ? ... 与 value as T? 含义不同。

## 模式选择器

```text
selector       = simple-selector ("|" simple-selector)* ;
simple-selector = "_" | literal | "(" selector-list ")" | variant-selector ;
variant-selector = variant-path ("[" selector-list "]")? ;
variant-path   = path | none-variant-path ;
selector-list  = selector ("," selector)* ","? ;
```

模式只选择，不绑定；path 必须解析为枚举变体，不允许普通变量作为模式。
组合模式必须给处理函数产生相同输入签名；否则拆成独立分支。嵌套选择仍把最外层变体的
完整负载传给处理函数。裸 _、标量、元组选择器传递整个匹配对象。
Maybe::None 显式路径在模式和表达式位置均放行；None 不允许声明为普通名称。
旧 match、模式 > / => 和选择器中的变量绑定不属于当前规范。

## 词法、恢复与诊断

- ::、:>、|>、<<、>>、..=、-> 等采用最长匹配，: 与 :> 是不同的完整符号。
- 1> / 2> 不作全局专用词法单元，而是数字加 >，由分支头语法识别；空格不影响比较。
- ?、[、return、] 分开识别，?[return] 的组合属于语法，不与类型修饰或索引混淆。
- [] 在声明/构造中是负载，在选择器中是筛选，在 handler 中是多参数附件，在 fn 后是
  捕获附件；均由明确的语法位置决定，不允许猜测变量名后的 @ 是声明还是取地址。
- 旧写法应提示迁移为 selector :> 参数 -> 正文或命名处理函数，不静默解释为新语义。
- 每个节点与标点保留源码范围；缺分号、缺通道、类型不符、不可调用目标提供具体诊断。
- 语法恢复同步到 ;、同层逗号或配对 }，继续报告后续独立错误。

## 首次自举边界

首次自举支持枚举分支、共享匹配、直接处理绑定、命名函数及无捕获匿名函数。
拥有捕获闭包可在随后独立阶段实现；借用捕获、可写视图匹配、动态闭包容器及复杂守卫
不阻塞自举。已规定的闭包与检查模式安全规则不能因为暂未实现而悄悄改成另一种含义。
