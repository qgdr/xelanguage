# 所有权、安全借用与生命周期

## Copy 与移动类型

标量、只读视图和只包含 `Copy` 字段的结构可以实现 `Copy`。以下类型不能实现 `Copy`：

- 实现了 `Drop` 的类型；
- 含有非 `Copy` 字段的类型；
- 标准库声明为资源所有者的类型，例如 `String`、`Vec[T]`、`File`。

`=` 复制；`<<` / `>>` 传递值。对非 `Copy` 类型，传递后源变量进入“已移动”状态：

```xe
let first: String << String::from("hello");
let second: String << first;

println("{}", first); // 编译错误：first 已移动
```

需要独立资源时显式克隆：

```xe
let first: String << String::from("hello");
let second: String << first.clone();
```

## 共享借用

`T@` 是非空、共享、只读借用。`value@` 取得共享借用：

```xe
let value: i32 = 5;
let pointer: i32@ = value@;

println("{}", pointer#);
```

共享借用存在期间：

- 可以建立更多共享借用；
- 不能通过它修改对象；
- 不能移动或析构所有者；
- 借用不能超过所有者的生命周期。

## 可写借用

`T@[mut]` 是非空、独占、可写借用。`value@[mut]` 取得这种借用：

```xe
var value: i32 = 5;
let pointer: i32@[mut] << value@[mut];

pointer# = 8;
```

同一对象存在可写借用时，不能同时存在其他共享或可写借用，也不能直接访问、移动或析构
所有者。借用在最后一次使用之后结束，而不是机械地持续到整个花括号结束。

`mut` 修饰的是借用能力，不是被借用对象的永久类型。只有可修改的存储位置才能产生
`@[mut]`；因此不可重新赋值的标量 `let` 不能取得可写借用，而拥有内部可变性的标准库类型
必须通过专门 API 明确表达。

共享借用实现 `Copy`；独占可写借用是移动类型，不能复制或同时传给两个接收者。

## 区域与生命周期

函数内部的借用区域由编译器推导。返回借用时，常见情况可以省略区域：

- 只有一个携带借用区域的输入时，返回值来自该输入；这包括 `T@`、`str`、`Slice[T]` 等；
- 方法返回借用时，默认来自 `self`。

这些规则同样适用于按值传递的只读视图，因为视图中的地址仍然不能超过底层所有者。多个
输入可能成为返回来源时，公开 API 必须写命名区域：

```xe
fn choose[region r, T](
    left: T@[r],
    right: T@[r],
    choose_left: bool,
) -> T@[r] {
    if choose_left { left } else { right }
}
```

可写借用和区域可以组合：

```xe
fn first_mut[region r, T](var items: SliceMut[T, r]) -> T@[mut, r] {
    items.first_mut()
}
```

区域只用于静态检查，不存在于运行时。首版不追求完整 Rust 生命周期系统，但必须拒绝返回
局部变量地址、借用期间移动所有者和共享/可写别名冲突。

## 解引用与方法访问

`pointer#` 显式读取所指对象。字段访问和方法调用允许受控自动解引用：

```xe
pointer.method(); // 等价于 pointer#.method()
```

格式化没有隐式借用或编译器自动解引用。标准库通过普通 Trait 实现，让 `T@` 在 `T` 可以
格式化时转发给 `T`；`{:p}` 则选择借用的指针格式：

```xe
println("value = {}", value@);      // 显式借用 value
println("address = {:p}", value@); // 显示借用地址
```

取得数值地址使用 `.addr()`：

```xe
let address: usize = pointer.addr();
```

地址整数不能直接转换回安全借用，因为它已经失去生命周期和来源信息。

## 裸指针

`RawPtr[T]` 是可能为空、没有借用保证的底层指针，仅用于运行库、设备访问和外部接口：

```xe
let raw: RawPtr[u8] = buffer.raw_data();
```

创建、运算和解引用裸指针必须位于 `unsafe` 块。普通 Xe 代码应使用安全借用、切片或数值 ID。
编译器自身保存长期关系时优先使用 `NodeId`、`TypeId` 和 Arena，而不是裸指针。
