# 整数运算与短路逻辑

同一机器整数类型支持 `+ - * / %`、一元 `-` 和六种比较 `== != < <= > >=`。
比较产生 bool。不同整数类型不会在运算时自动扩大或合并类型。
bool 支持 `and`、`or`、`not`。

```xe-core
fn quotient(left: i32, right: i32) -> i32 { left / right }

fn main() -> Unit {
    let left: i32 = -7;
    let right: i32 = 3;
    let product: i32 = left * right + 1;
    let ready: bool = product < 0 and not false;
    println("{} {} {} {}", product, quotient(left, right), left % right, ready);
}
```

输出 `-20 -2 -1 true`。整数除法向零截断；非零余数与被除数同号。
除数为零，以及有符号最小值除以 -1 或对 -1 取余，都失败。
加、减、乘、取负逐步检查范围，不允许先溢出再通过外层运算恢复。

```xe-invalid
let bad: i8 = (127 + 1) - 1; // 中间结果已经越界。
let zero: i32 = 7 / 0;
```

字面量算术树可以确定的失败报编译错误；动态输入引起的失败触发 panic。
优化级别不改变这条规则。当前 panic 直接终止，不保证析构，也没有捕获或栈展开接口。

`and/or` 短路：`false and f()`、`true or f()` 不调用 f，但右侧仍须通过语法和类型检查。

当前运算优先级由高到低为：

| 层级 | 操作 |
| --- | --- |
| 后置访问 | 调用、字段、索引、限制、@、#；同层按源码顺序组合 |
| 一元 | -、not |
| 乘除 | *、/、% |
| 加减 | +、- |
| 比较 | ==、!=、<、<=、>、>=；只比较两个操作数 |
| 布尔 | and 高于 or |

同一算术层从左向右结合；普通括号用于明确不同分组。
赋值和转移是语句，不在这张算术优先级表中。
当前不支持比较链、位运算、浮点和数值转换。
