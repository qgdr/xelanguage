# 开始阅读 Xe 程序

先认识四个基本约定：`名字: 类型` 标注类型，`()` 调用函数或分组，
`{}` 包围代码块，`;` 结束语句。代码块最后一个没有分号的表达式产生该块的结果。

```xe-core
fn add(left: i32, right: i32) -> i32 {
    left + right
}

fn main() -> Unit {
    let answer: i32 = add(20, 22);
    println("{}", answer);
}
```

输出 `42`。`fn` 定义函数，参数放在圆括号中，`-> i32` 表示正常返回一个 i32 量。
`main` 是程序入口，当前使用无参数、返回 `Unit` 的形式。
`Unit` 表示正常完成而没有业务结果；其值写作 `unit`。

`let answer: i32` 建立名为 answer 的盒子，`=` 将可复制的结果保存进去。
每个局部声明都必须写出类型，函数的参数和返回类型也必须写出。
因此，上面两个整数字面量从 add 的 i32 参数取得类型，不依赖默认整数类型。

`println` 的第一个参数是文本模板；每个 `{}` 对应一个后续实参。
调用本身以分号结束，不参与 main 的块结果。
普通函数、分组和块可以直接组合，不需要给每个函数调用额外包一层块。
