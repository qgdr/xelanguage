# 当前功能边界

当前默认编译器接受本文手册描述的核心形式。语法或行为尚未支持时会拒绝，
不会自动把同一程序切换成另一套语言含义。
名字当前使用 ASCII 标识符；单独的 `_` 保留为忽略输入，不是普通变量名。
字符串内容可以使用 Unicode 文本。

```xe-core
fn read(values: Array[i32,2]@, index: usize) -> i32 {
    values#⟦index⟧
}

fn main() -> Unit {
    let values: Array[i32,2] = [10,20];
    let result: i32 = read(values@, 1);
    println("{}", result);
}
```

输出 `20`。动态坐标越界会触发 panic；这不是把无效内存访问留给程序继续执行。
成功编译也不保证所有动态输入都满足边界，更不代表已经验证未写入程序的业务需求。

当前主要支持：

- 显式类型的局部声明、函数、块、if、while、return、无标签 break/continue。
- 机器整数和 bool 运算、普通指针及本级写权限、Copy 与显式转移。
- 非泛型结构体、显式 Copy、基本方法、完整资源构造和整体清理。
- Copy 数组索引、原坐标局部 View，以及资源数组的整体操作。
- 透明别名、有限集合／同载体并集的编译期声明、非泛型枚举和分支交付。
- 最小显式泛型函数、String 构造／clone、println 和直接终止的 panic。

下列功能当前不可用：

| 类别 | 边界 |
| --- | --- |
| 结果／可选类型 | T?、T?[E]、None 普通类型、编号通道、错误传播附件 |
| 类型与能力 | newtype、通用 Trait、自定义 Drop、泛型 struct/enum、泛型参数推断 |
| 函数抽象 | 函数值、闭包、捕获、生成器、迭代协议和 for |
| 接口与工具能力 | 语言级模块导入、pub、全局变量、extern/FFI、跨目标 ABI |
| 值与计算 | 元组、浮点、字符／字节、位运算、数值转换、比较链、默认整数类型 |
| 文本与视图 | 字符串转义、额外格式规则、其他文本方法、View 参数／返回／字段／别名 |
| 部分资源操作 | 非 Copy 字段或数组元素单独移出、逐字段构造、资源元素索引／视图／覆盖 |
| 失败恢复 | panic 捕获、栈展开与资源清理保证 |

普通指针允许别名，不提供完整独占借用或任意原始指针的静态有效性保证。
已知来源寿命错误会被拒绝；未知来源可能给出风险警告，部分写回组合当前直接拒绝。
warning 仍允许编译，不是运行安全的证明；`[unsafe]` 注记也不会修复悬垂目标。
