# 数组索引与保留原坐标的视图

`Array[T,N]` 拥有 N 个 T 元素。`a⟦i⟧` 只做单点索引，找到 T 元素盒子；
取地址另写 `a⟦i⟧@`。`⟨范围⟩` 只做连续坐标限制，不兼作单点索引。

`a⟨l..u⟩[@]` 建立非拥有的地址映射，类型为 `View[T@]`。
可写来源用 `[@[mut]]` 建立 `View[T@[mut]]`。
View 的参数 P 是完整定位结果类型；`w⟦i⟧` 产生 P 指针量，`w⟦i⟧#` 才找到目标盒子。

```xe-core
fn main() -> Unit {
    let[mut] a: Array[i32,4] = [10,20,30,40];
    let copied: i32 = a⟦1⟧;
    let direct: i32@ = a⟦1⟧@;
    let r: View[i32@] = a⟨1..3⟩[@];
    let w: View[i32@[mut]] = a⟨1..3⟩[@[mut]];
    let child: View[i32@[mut]] = w⟨1..2⟩;
    a⟦1⟧ = 77;
    child⟦1⟧# = 99;
    let same: i32 = r⟦1⟧#;
    println("{} {} {} {}", copied, direct#, same, child⟦1⟧#);
}
```

输出 `20 99 99 99`。child 的坐标仍是来源坐标 1，不重新编号为 0。
限制已有 View 保留 P，包括这一层指针的可写权限；描述符 Copy 不复制元素，也不延长来源生命期。
描述符盒子是否可改写，由它的 let/let[mut] 决定，与 P 的写权限分别判断。

连续范围使用 `l..u` 表示左闭右开，使用 `l..=u` 表示两端包含，`..` 表示当前完整域。
请求必须包含于当前域；空范围可位于域内及尾边界。已知越界报错，动态越界 panic；不裁剪、不回绕。
坐标使用 usize，不支持离散索引列表或只省略一个端点。

```xe-invalid
a⟨1⟩;       // 限制需要范围；单点写 a⟦1⟧。
a⟦1..3⟧;    // 索引只接受一个坐标。
a⟦1⟧[@];    // 范围地址映射附件不适用于单点。
w⟦1⟧@;      // View 索引已经产生指针量，不是保存该指针的盒子。
```

这里区分的是表达式找到盒子还是产生量，不是给 i32 增加“盒子类型”。
Array 的定位能力可抽象为从坐标域到元素地址的映射；这不把数组声明成普通函数。
View 限制只缩小这个映射的定义域，保留结果指针层级。

当前这些元素访问支持 Copy 元素。资源数组先只支持[资源数组的整体操作](12-resource-arrays.md)。
View 当前只用于局部直接类型标注，不支持参数、返回、字段、类型别名或一般权限转换。
数组和 View 不使用 `a(i)` 或普通方括号索引。
