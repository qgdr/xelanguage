# 版本与兼容

[文档首页](README.md) · [发布契约](../RELEASE.md)

当前交付名为**Xe Core Preview 1**，版本`0.1.0-alpha.1`，语法标识`xe-core-0.1`。
Python元数据的`0.1.0a1`表示同一预览版本；AST信封schema版本仍为1。

本版发布边界以[支持表](support.md)为准。旧玩具编译器的候选版本、样例和兼容实现
不构成本版的功能或兼容承诺。

## 预览期约定

预览版适合试写程序、复现问题和比较规则。源码可能有不兼容修正，不能当作稳定1.0接口。
类型和资源错误可能因修复而更早被拒绝；诊断文字及生成C可能变化。
工具应读取版本、AST schema和结构化诊断，不能匹配中文句子或C内部符号。

## 获取与检查源码包

源码包命名为`xelanguage-0.1.0-alpha.1-source.tar.gz`，附SHA-256摘要与文件清单。
包内不带Python、GCC或虚拟环境。安装环境见[快速开始](getting-started.md)。
发布验收包含从包外目录编译执行核心示例，且不借用维护者的根虚拟环境。
文件完整性校验不等于编译器正确性证明；本地候选包生成也不意味着远端已经发布。
