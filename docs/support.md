# Core Preview 1 支持范围

[文档首页](README.md) · [语言手册](language.md)

本页描述默认core实际接入的有限范围。已讨论过但尚未实现的设计，不算本版功能。

| 类别 | 当前支持 | 主要边界 |
| --- | --- | --- |
| 基础 | 显式局部类型、具名函数、块结果、if、while、return及普通break/continue | 没有完整控制流精度，某些循环初始化组合保守拒绝；无标签/带值跳转 |
| 整数与布尔 | 十种机器整数、同型算术和比较、bool短路 | 溢出/除零等静态报错或动态panic；无隐式整数扩大、转换、浮点、位操作或比较链 |
| 存储与资源 | Copy复制、显式双向转移、延后初始化、可变重建、完整对象正常退出清理 | 资源字段部分移出、逐字段构造和复杂资源写回未开放 |
| 数据 | 非泛型struct、显式Copy、基本方法、零/一个整体负载的非泛型enum | 不自动Copy；无一般Trait、泛型数据类型或用户Drop；禁止enum自定义Drop |
| 数组 | 固定Array，Copy元素定位；资源Array完整构造/整体传递/清理 | 资源元素索引/视图、单个资源移出和整体重组元组未开放 |
| 指针 | T@、T@[mut]、@/#、一层字段简写与基本只读降权 | 允许别名，不是独占引用；不自动取得目标所有权或延长寿命 |
| View | Copy元素的局部View[P]，来源坐标、严格边界、空锚点、可写映射 | 不能作参数/返回/字段/别名；无一般权限转换或公开布局承诺 |
| 类型声明 | 透明别名、前向非循环依赖；同载体有限set/union声明 | 集合声明域不能放进运行值槽；跨载体并集与newtype尚未接入 |
| 泛型 | 具名`fn[T]`、显式`f[Type](...)`，模板先检查 | 无实参推断、能力约束、泛型函数值/管道目标或泛型struct/enum |
| 基本输出 | 当前格式化println与String最小接口 | 格式字符串须为文字；不是完整标准库或自定义格式化协议 |

所有局部let都写类型。Array长度使用非负整数字面量，实际可构建尺寸受平台和工具链约束。
只读或可写View的P是完整定位结果指针类型，不能把View[T]默认为View[T@]。

## 失败与资源清理

读取前必须能确定已经初始化；移动后的直接来源不可再读取。
完整构造中途退出，只清理已经构造且仍拥有的成员。
正常退出、return及已接入的普通循环跳转按实际退出范围清理资源。

panic首版采用Abort：报告并终止，不保证调用析构，不承诺异常恢复或展开。
优化构建不改变整数溢出和View边界规则。

## 指针保证的范围

已知短本地来源不能写入更长存活槽或逃逸返回，这类确定的词法风险是error。
未知来源、目标被后续操作失效等风险可能只有warning；warning仍可构建。
通过编译不等于所有原始指针都有效，也没有完整内存安全、无线程竞争或任意程序无泄漏的保证。
不要执行已被诊断为悬垂风险的示例来验证结果。

## 本版范围外

模块/use/pub、全局变量、外部C接口、动态容器、元组、闭包、迭代器、线程、智能指针、
完整Trait、浮点和转换均不属于本版。
T?、T?[E]、编号分流与传播也尚未开放；None不是负载类型，T?[None]不是T?的替代拼写。
源代码中出现这些形状时，编译器应明确拒绝，不隐式采用旧兼容语义。

预览期允许根据反馈修正规则或收紧误接收的程序，变化记入[更新日志](../CHANGELOG.md)。
