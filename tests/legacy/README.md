# 历史语言阶段档案

这里保存早期设计讨论和已删除旧编译器的源程序，**不是现行语言规范或候选版支持承诺**。
现行正例在 [language](../language/README.md)，现行规则从 [doc/00.md](../../doc/00.md) 阅读。

- `stage01` 至 `stage04`：旧宿主编译器的分阶段例子。
- `stage903`、`stage904`：当时的块表达式、绑定、控制流及指针/借用设计草案。

保留原阶段目录和源码内容便于追溯，不要求这些程序通过当前解析器、语义或后端。
其中旧关键字、类型或符号不能因为“档案中存在”就被重新赋予正式语义。
历史编译产物保持原位置并由 `.gitignore` 排除；目录整理不删除或搬运它们。
