# 测试目录

- `stage01` 至 `stage04` 保存早期宿主编译器的历史阶段样例；旁边的 `.ast.json`、`.ll` 和
  `.out` 是旧实验生成物，不是目标规范。
- `stage903`、`stage904` 保存块表达式、可变绑定、借用和控制流设计样例。
- `stage999` 保存完整目标语法样例，新的编译器按功能逐步让这些样例通过。
- `fails` 中的程序必须编译失败；测试工具还要校验错误代码、源码范围和关键提示文字。

实现一个功能时，应同时增加：

1. 正常成功样例；
2. 边界样例；
3. 至少一个失败样例；
4. 面向使用者的诊断快照。

## 指针模式与目标语法测试

现有借用设计样例默认按 --check-borrows 验收，尤其是带 @[mut] / 区域的文件。
stage999/pointer_unchecked.xe 则在默认模式验收，并在检查模式确认其写入被拒绝。
资源所有权失败样例在两种模式都必须失败；借用别名与悬垂样例只在检查模式要求失败。
当前旧编译器未支持这些目标功能，不可把解析失败当作正确的所有权诊断。
